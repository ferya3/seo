# content

کدام کلمه‌های کلیدیِ تحقیق‌شده صفحه‌ای دارند، و کدام صفحه‌ها سر یک عبارت با هم
رقابت می‌کنند.

```bash
uvicorn services.content.api:app --port 8006
python -m services.content.worker
```

| فایل | کارش |
| --- | --- |
| `analyze.py` | همه‌ی قضاوت‌ها؛ تابع خالص روی دو دیکشنری — بدون شبکه و دیتابیس |
| `source.py` | دو گزارش بالادستی: خزش و تحقیق کلمات کلیدی |
| `store.py` | یک `JobTable` روی `content_analyses` |
| `api.py` | `POST /v1/content-analyses` + خواندن نتیجه |
| `worker.py` | مصرف `content.analysis_requested` |

## چرا این سرویس

این اولین تحلیلی است که **همزمان به دو مرحله‌ی قبلی نیاز دارد**: خزش می‌داند چه
صفحه‌هایی وجود دارد و هر کدام خودش را درباره‌ی چه چیزی اعلام می‌کند، تحقیق کلمات
کلیدی می‌داند مردم دنبال چه می‌گردند. هیچ‌کدام به‌تنهایی جواب نمی‌دهند و هیچ
قانونی داخل موتور هم نمی‌تواند، چون موتور اصلاً تحقیق کلمات کلیدی را نمی‌بیند.

- **شکاف** — عبارتی که تقاضا دارد و هیچ صفحه‌ای برایش نیست: یک صفحه که باید
  نوشته شود، با عدد تقاضایش
- **رقابت داخلی (cannibalisation)** — چند صفحه روی یک عبارت. سیگنال بین‌شان
  تقسیم می‌شود و هر دو بدتر از یکی رتبه می‌گیرند؛ ممیزی صفحه‌به‌صفحه هرگز این را
  نمی‌بیند چون هر صفحه به‌تنهایی سالم است
- **صفحه‌های بی‌هدف** — صفحه‌ای که به هیچ‌کدام از عبارت‌های تحقیق‌شده نمی‌خورد.
  الزاماً ایراد نیست (صفحه‌ی «درباره ما» نباید عبارت تجاری هدف بگیرد)، برای
  همین فهرست است نه شمارش خطا

## تصمیم‌ها

**تطبیق روی چیزی که صفحه اعلام می‌کند، نه متن بدنه.** عنوان، توضیح متا و
تیترها. متن بدنه یعنی کل خزش دوباره در حافظه، و صفحه‌ای که یک بار در یک
پاراگراف عبارتی را آورده، آن عبارت را هدف نگرفته. این یک محدودیت واقعی است و
داخل خود گزارش (`method`) نوشته می‌شود، نه اینکه کسی بعداً کشفش کند.

**دو سوم کلمه‌ها باید باشد.** «کفش ورزشی مردانه» با صفحه‌ای درباره‌ی «کفش ورزشی
مردانه ساق بلند» جور است ولی با صفحه‌ای که فقط «کفش» می‌گوید نه. آستانه‌ی
پایین‌تر یعنی هر صفحه همه‌ی عبارت‌ها را ادعا کند و فهرست شکاف‌ها خالی و بی‌فایده
شود.

**فارسی یک املا دارد.** «ي» عربی به «ی»، «ك» به «ک»، نیم‌فاصله مرز کلمه،
اعراب و کشیده حذف. بدون این، صفحه‌ای با عنوان «کفش ورزشي» هرگز با کلیدواژه‌ی
«کفش ورزشی» جور نمی‌شد و گزارش، کاری را که انجام شده «انجام‌نشده» می‌گفت.

**صفحه‌ی noindex نه پوشش می‌دهد نه رقابت می‌کند.** صفحه‌ای که اجازه‌ی ایندکس
ندارد نمی‌تواند صفحه‌ی پوشش‌دهنده باشد، و گزارش کردنش به‌عنوان رقیب یعنی فرستادن
کسی به بازنویسی صفحه‌ای که از اول شانسی نداشته.
