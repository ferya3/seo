# optimizer

اولین سرویسی که به‌جای گزارش دادن، **پیشنهاد می‌دهد**.

```bash
uvicorn services.optimizer.api:app --port 8007
python -m services.optimizer.worker
```

| فایل | کارش |
| --- | --- |
| `analyze.py` | تصمیم می‌گیرد چه صفحه‌ای، چه چیزش، و هر اصلاح باید چه شرطی را برآورده کند |
| `rewrite.py` | لایه‌ی مدل: متن را می‌نویسد، و پاسخی که شرط‌ها را رد کند دور ریخته می‌شود |
| `source.py` | گزارش خزش (لازم) و تحقیق کلمات کلیدی (اختیاری) |
| `store.py` | یک `JobTable` روی `optimizer_plans` |
| `api.py` / `worker.py` | دو در، یک `run_plan` |

## دو لایه، و اینجا لایه‌ی دوم واقعاً کار می‌کند

**لایه‌ی قانون** تصمیم می‌گیرد کدام صفحه ارزش وقت دارد، چه چیزی ایراد دارد، و
هر اصلاح باید چه شرطی داشته باشد: کدام عبارت هدف، چه بازه‌ی طولی، آیا عبارت
باید در متن بیاید. هر جا بشود بدون ساختن چیزی از خودمان کاندیدا داد، می‌دهد —
عنوان بلند را سر مرز کلمه کوتاه می‌کند (اول برند را می‌اندازد، چون همان چیزی
است که خواننده در دامنه می‌بیند)، عنوان نداشته را از H1 خود صفحه می‌سازد. جایی
که کاندیدا دادن یعنی نوشتن متن، **نمی‌نویسد**.

**لایه‌ی مدل** متن را می‌نویسد. بدون کلید API، خروجی یک دستورالعمل دقیق است نه
جمله‌ای که کسی از خودش درآورده — همان معنی صادقانه‌ی «مسیر رایگان همیشه کار
می‌کند».

**پاسخ مدل کورکورانه پذیرفته نمی‌شود.** بازنویسی‌ای که از بازه‌ی طول بیرون
بزند، عبارت هدفی را که خواسته شده نداشته باشد، یا خالی برگردد دور ریخته
می‌شود و کاندیدای قانونی سر جایش می‌ماند. مدل نویسنده‌ی بهتری است؛ داور بهتری
برای شرط‌هایی که قانون گذاشته نیست.

## چند تصمیم دیگر

**عنوان بدون عبارت هدف کاندیدا نمی‌گیرد.** چسباندن مکانیکی کلیدواژه دقیقاً
همان عنوان اسپم‌شده‌ای را می‌سازد که این ابزار قرار است علیهش استدلال کند.

**صفحه به عبارتی وصل می‌شود که از قبل درباره‌اش حرف می‌زند**، نه به پرتقاضاترین
عبارت. بین دو تطبیق کامل، **خاص‌تر** برنده است نه پرجستجوتر: صفحه‌ای که «کفش
دویدن مردانه» را کامل پوشش می‌دهد درباره‌ی همان است، نه درباره‌ی «کفش».

**فهرست کوتاه است.** پیش‌فرض پنج صفحه، سقف بیست‌وپنج. هر صفحه هم توکن مدل است و
هم کاری که یک آدم باید انجام دهد؛ صد بازنویسی فهرستی است که کسی شروعش نمی‌کند.

**تحقیق کلمات کلیدی اختیاری است.** اصلاح طول و ساختار به عبارت هدف نیاز ندارد،
پس سایتی که تحقیقش خالی برگشته باز هم طرح قابل‌استفاده می‌گیرد.
