# internal-links

آنچه لینک‌های خود سایت درباره‌ی سایت می‌گویند.

```bash
uvicorn services.internal_links.api:app --port 8004
python -m services.internal_links.worker
```

| فایل | کارش |
| --- | --- |
| `analyze.py` | همه‌ی قضاوت‌ها؛ تابع خالص روی یک گراف — بدون شبکه، بدون دیتابیس |
| `source.py` | تنها جایی که به سرویس Crawl وصل می‌شود |
| `store.py` | یک `JobTable` روی `link_analyses` |
| `api.py` | `POST /v1/link-analyses` + خواندن نتیجه |
| `worker.py` | مصرف `links.analysis_requested` |

پوشه `internal_links` است نه `internal-links`: خط تیره اسم ماژول پایتون
نمی‌شود و بقیه‌ی سرویس‌ها با `from services.x import ...` وارد می‌شوند.

## چرا این سرویس، وقتی موتور قبلاً قوانین لینک دارد

موتور می‌بیند که یک صفحه یک لینک ورودی دارد. فقط گراف می‌تواند بگوید ساختار
خود سایت، صفحه‌ی «تماس با ما» را مهم‌ترین دارایی‌اش می‌داند در حالی که مقاله‌ای
که یک هفته وقت برده گوشه‌ی گراف افتاده. چیزهایی که اینجا حساب می‌شوند و قانون
نمی‌تواند:

- **اعتبار داخلی** (PageRank داخلی، نرمال‌شده روی ۱۰۰) — سایت با لینک‌هایش چه
  چیزی را مهم اعلام کرده
- **صفحات نادیده‌گرفته‌شده** — محتوا دارند، لینک ورودی تقریباً ندارند، و اعتبار
  داخلی‌شان زیر میانه است؛ ارزان‌ترین کار ممکن روی سایت
- **لینک به صفحه‌ی خراب یا noindex** — لینکی که خرج می‌شود و چیزی برنمی‌گرداند
- **صفحاتی که فقط با «اینجا» لینک می‌گیرند** — لینک دارند و سیگنال کلیدواژه‌ای
  ندارند
- **بن‌بست‌ها** و **هیستوگرام عمق**

## تصمیم‌ها

**گراف از خزش می‌آید، نه از خزش دوباره.** گزارش خزش حالا یال‌ها را هم دارد
(`links.edges`)، با سقف پنجاه هزار یال و پرچم `truncated`. گراف ناقصی که خودش
نگوید ناقص است، جواب غلط درباره‌ی صفحات یتیم می‌دهد.

**تنها تماس سرویس‌به‌سرویس این پروژه.** همه چیز روی باس رد و بدل می‌شود چون
همه چیز خلاصه است؛ گزارش خزش خلاصه نیست. رویداد `crawl.completed` از اول
`result_url` را حمل می‌کرد تا هرکه لازم دارد خودش بگیرد — این همان‌جاست.
`tenant_id` هم با درخواست می‌رود، وگرنه این سرویس تبدیل می‌شد به راهی برای
خواندن خزش هر تنانتی با یک شناسه.

**لینک `nofollow` داخلی دنبال می‌شود.** گوگل از ۲۰۱۹ آن را دستور نمی‌داند، و
سایتی که لینک‌های داخلی خودش را nofollow می‌کند باز هم دارد ساختارش را توصیف
می‌کند. تعدادشان جداگانه گزارش می‌شود.

**یک هدر و یک فوتر، یک رأی.** لینک ورودی بر اساس صفحه‌ی لینک‌دهنده شمرده
می‌شود نه تعداد تگ، وگرنه هر آیتم منو پرقدرت‌ترین صفحه‌ی سایت به نظر می‌رسد.
